# Smart Recycling Hub (SRH)

> Redefining Recycling in South Africa

An interactive web app for **Smart Recycling Hub** — AI-powered smart recycling bins placed in high-traffic public areas (taxi ranks, schools, malls, markets) that reward South Africans with redeemable points for every item they recycle.

**Developer:** Joshua Haswell (ST10437907) — ENTP6211w Entrepreneurship

## Pages

- `index.html` — Landing page (hero, problem, how it works, features, impact, CTA)
- `dashboard.html` — Interactive Discovery-Bank-style user dashboard with:
  - Progress ring to next tier
  - Material breakdown
  - Points & rewards centre with live redemption
  - Drag-and-drop recycling simulator
  - Tier cards (Green Starter / Champion / Legend)
  - Community leaderboard
  - Hub locator map
- `rewards.html` — Tier system, points table, bonus challenges
- `partners.html` — Ecosystem partners and revenue model

## Tech

Pure HTML / CSS / vanilla JS. No frameworks. Mobile-first. Persisted via `localStorage`.

## Run

Open `index.html` in any browser, or serve with `python3 -m http.server`.
